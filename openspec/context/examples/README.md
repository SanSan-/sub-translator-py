# Проверяемые примеры

Примеры связывают требования с реализацией и проверками. Наличие теста не подтверждает успешный прогон.

| Требование                                                                                                 | Сценарий и конкретный результат                                                                                                                                           | Рабочий вход / тест                                                                                                                                                                   | Граница                                                                     |
|------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------|
| [MODEL-002](../../specs/model-runtime/spec.md#requirement-model-002-единственный-локальный-слот)           | Активен NLLB; его unload бросает ошибку; создание TranslateGemma с timeout=20 не происходит, active_profile_id остаётся nllb-600m                                         | [lifecycle.py](../../../sub_translate/translators/lifecycle.py), [test_unload_failure_preserves_active_state_and_blocks_next_profile](../../../tests/test_translator_lifecycle.py)    | Имитации адаптеров; не освобождение реальной VRAM                           |
| [WEB-003](../../specs/local-web/spec.md#requirement-web-003-подготовка-и-настройки)                        | pick поколения 1 сменён refresh поколения 2; поздний update старой операции возвращает false и не попадает в журнал                                                       | [preparation.py](../../../sub_translate/web/preparation.py), [test_preparation_tracker_ignores_stale_updates_and_bounds_history](../../../tests/test_web_preparation.py)              | Проверка объекта состояния; не весь браузерный поток                        |
| [SUB-007](../../specs/subtitle-translation/spec.md#requirement-sub-007-идентичность-готового-кеша)         | Ранее закеширован Hello→Привет; выход удалён, модель отсутствует либо неполна; результат CACHED, выход восстановлен без сети/секрета/адаптера                             | [service.py](../../../sub_translate/service.py), [test_manual_model_cache_restores_without_model_network_secret_or_adapter](../../../tests/test_service.py)                           | Временные файлы и запретные заглушки; не новое качество модели              |
| [MODEL-004](../../specs/model-runtime/spec.md#requirement-model-004-разрешённая-загрузка-и-восстановление) | Ошибка принудительного обновления оставляет прежнюю цель; тест проверяет отсутствие лишнего staging                                                                       | [huggingface.py](../../../sub_translate/utils/huggingface.py), [test_failed_forced_refresh_preserves_target_and_removes_staging](../../../tests/test_model_acquisition.py)            | Сценарий имитации; не обещание отката при двойном системном отказе          |
| [SUB-008](../../specs/subtitle-translation/spec.md#requirement-sub-008-кеш-запросов-и-статистика)          | Статистика пишет 4 входных и 5 выходных токенов атомарно в UTF-8                                                                                                          | [usage_tracker.py](../../../sub_translate/utils/usage_tracker.py), [test_record_usage_writes_utf8_atomically](../../../tests/test_usage_tracker.py)                                   | Учёт тестового ответа, не финансовые измерения                              |

Для [принудительного нового перевода](../../specs/subtitle-translation/spec.md#scenario-принудительный-новый-перевод)
готовый кеш соответствует файлу, но выбран `force=true`: [вход общего конвейера](../../../sub_translate/service.py)
обходит восстановление готового кеша и запускает новый перевод. Этот статический пример не подтверждает выполненный
прогон или отключение независимого кеша запросов OpenAI; граница — SUB-007/008.
