# ADR-004: Авторитетное состояние веб-задачи

- Статус: принято.
- Пересмотр: при изменении перечисленных границ.

## Контекст

Долгий выбор и потеря SSE могут оставить UI со старым состоянием.

## Решение

Поколение подготовки, ограниченный снимок задачи и получение снимка после разрыва; завершение старой задачи не снимает
блокировку новой.

## Последствия

Серверное состояние отделено от доставки событий; 10000 элементов хранятся с отображением до 200 карточек.

## Альтернативы

HTTP-ответ или последнее SSE как единственный признак завершения не приняты.

## Свидетельства и ограничения

web/preparation.py; web/app.py; web/static/app.js; tests/test_web_preparation.py. Компоненты и проверки перечислены
в [примерах](../examples/README.md) — наличие теста не подтверждает его выполнение.
