# ADR-003: Полная идентичность и публикация модели

Статус: ретроспективная фиксация существующего архитектурного решения. Пересмотр — при изменении источника доверия к весам или способа безопасной публикации снимка.

## Контекст

Одинаковый путь каталога не гарантирует неизменность весов. Повреждённое обновление требует восстановления прежних данных.

## Решение

Доверие к модельным данным опирается на проверяемое содержимое и объявленную ревизию, а не только на путь.
Подготовка и проверка нового снимка предшествуют его публикации. При неуспешном восстановлении прежние данные
сохраняются для ручного восстановления.

## Альтернативы

- Путь как единственный идентификатор не позволяет обнаружить смену содержимого.
- Безусловная загрузка из сети не учитывает пригодность полного локального снимка.
- Обещание успешного отката при любом отказе не учитывает самостоятельный отказ восстановления.

## Последствия

Проверка содержимого имеет стоимость; полный ручной снимок может быть пригоден локально без подтверждения происхождения
закреплённой ревизии. Ошибки публикации и восстановления рассматриваются раздельно; при двойном системном отказе
сохранённые прежние данные требуют ручного восстановления.
