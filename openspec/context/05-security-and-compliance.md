# Безопасность данных и интеграций

Указатель на контракты защиты пользовательских данных, моделей и секретов. Он помогает выбрать нужную спецификацию;
полные условия находятся у владельца требования.

| Область | Контракт |
|---------|----------|
| Источники, результаты, разрешение замены и явный сетевой поставщик | [SUB-002/009/010](../specs/subtitle-translation/spec.md) |
| Каталоги моделей, ревизии, загрузка, резервные копии и изоляция | [MODEL-001…008](../specs/model-runtime/spec.md) |
| Адрес клиента, Host/Origin и схема локального API | [WEB-001](../specs/local-web/spec.md) |

Переносимый пример настроек: [.env.example](../../.env.example). Источник профилей, ревизий и лицензий:
[реестр](../../sub_translate/translators/registry.py).
