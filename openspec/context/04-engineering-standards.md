# Стандарты и команды

Обязательны [общий Python-профиль](../specs/engineering-governance/reference/python-common.md)
и [локальное приложение](../specs/engineering-governance/reference/project-specific.md). Последнее хранит команды,
версии и все дополнительные ограничения; используй фактическую конфигурацию проекта.

Текущий пакет — 0.2.3, основная среда CPython 3.14, граф `pyproject.toml` + `uv.lock`; runtime/изолированные среды не
изменяются при документационной работе.

Из корня репозитория для документов: `openspec validate --all --strict --no-interactive`, проверка ссылок и UTF-8 без
BOM. Для изменений кода команды и порядок выбираются по локальному приложению; объём запуска соответствует изменению.
