# Словарь

| Термин               | Значение в проекте                                                          |
|----------------------|-----------------------------------------------------------------------------|
| Профиль              | Запись реестра с ID/алиасами, моделью, закреплённой ревизией и средой       |
| Мощность пачки       | Число элементов; каждому входу соответствует один строковый выход           |
| Готовый кеш          | Валидированный результат файла с полной идентичностью                       |
| Кеш фрагментов       | Ограниченные ответы запросов OpenAI; отличается от готового кеша            |
| Полный отпечаток     | SHA-256 проверяемых модельных файлов; путь сам по себе не идентичность      |
| Отметка версии 2     | Свидетельство модели/ревизии только при совпавшем полном отпечатке          |
| Локальный слот       | Один активный профиль, защищённый общей блокировкой                         |
| Поколение подготовки | Идентичность выбора/обновления; поздние события старого выбора не действуют |
| force                | Разрешение пересоздать вычисленную цель; не разрешение менять исходник      |
| Статический PASS     | Проверка документа или чтение кода; не запуск модели и не качество перевода |
