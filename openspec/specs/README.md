# Карта спецификаций

Документы формируют исходную спецификацию существующего приложения. Фактическое поведение описывается по исходникам
и проверкам; новое целевое поведение требует отдельного принятого решения. История приложения сохраняется отдельно
от формирования этой спецификации.

| Область                                                        | Единственный владелец требований                                                                                                                                                                            |
|----------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Форматы, публикация, кеши, сетевые поставщики и настройки      | [Перевод субтитров](subtitle-translation/spec.md)                                                                                                                                                           |
| Модельные данные, получение, ресурсы и изолированные процессы  | [Модельный контракт](model-runtime/spec.md)                                                                                                                                                                 |
| Локальная граница доступа, выбор файлов и состояние задач      | [Веб-контракт](local-web/spec.md)                                                                                                                                                                           |
| Инженерные ограничения среды и критерии приёмки переводчика | [Инженерная спецификация](engineering-governance/spec.md), [проектные команды и ограничения](engineering-governance/reference/project-specific.md) |

[Архитектура](../context/03-architecture.md) описывает ответственность и потоки,
[ADR](../context/ADR/README.md) — причины крупных решений.
Пользовательский вход — [README](../../README.md).
