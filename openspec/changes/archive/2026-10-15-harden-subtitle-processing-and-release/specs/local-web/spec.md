## MODIFIED Requirements

### Requirement: WEB-001 Локальная граница и схемы

Веб-сервис SHALL по умолчанию слушать 127.0.0.1 и требовать петлевой адрес клиента и адресуемого узла (`Host`);
переданный источник изменяющего запроса (`Origin`) должен совпадать с текущим узлом. Заголовки перенаправления
(`Forwarded`) MUST NOT доказывать локальность. Все локальные API-клиенты считаются доверенными; отсутствие `Origin`
у локального клиента SHALL допускаться без отдельной авторизации. Схема SHALL отклонять неизвестные поля;
ограничения на секреты определяются
[SUB-010](../../../../../specs/subtitle-translation/spec.md#requirement-sub-010-настройки-секреты-и-cli).
Ответ HTTP 422 не отражает входные значения; пустые необязательные пути нормализуются в `null`.

Каждый HTTP-ответ приложения, включая статические ресурсы, ранние отказы и ошибки, SHALL содержать
`Content-Security-Policy` с `frame-ancestors 'none'` и `X-Frame-Options: DENY`. Интерфейс MUST NOT допускать
встраивание в другую страницу; обычное открытие в отдельной вкладке SHALL сохранять работоспособность.
Запрет встраивания не заменяет проверку клиента, Host и переданного Origin.

#### Scenario: Локальная граница и схемы

- **WHEN** изменяющий запрос содержит внешний Origin
- **THEN** операция отвергается без старта перевода или выгрузки.

#### Scenario: Пустые пути файлов подсказок

- **WHEN** `agent_system_prompt_file` или `agent_prompt_file` содержит пустую строку либо только пробелы
- **THEN** схема нормализует значение в `null`; чтение файла по этому значению не выполняется.

#### Scenario: Доверенный локальный клиент без Origin

- **GIVEN** адрес клиента и Host допустимы и остальные условия операции выполнены
- **WHEN** локальный клиент отправляет изменяющий запрос без Origin
- **THEN** отсутствие Origin само по себе не вызывает отказа и не требует нового секрета доступа.

#### Scenario: Политика присутствует на отказах

- **WHEN** приложение возвращает обычный ответ, статический ресурс либо отказ HTTP 403, 404, 422, 500 или 503
- **THEN** оба заголовка запрета встраивания присутствуют; статус, тело и допустимые побочные эффекты операции
  сохраняют собственный контракт.

#### Scenario: Встраивание из другого источника

- **GIVEN** браузер может обратиться к локальному приложению и верхняя страница имеет другой источник
- **WHEN** верхняя страница пытается загрузить интерфейс в iframe
- **THEN** браузер блокирует встраивание по политике приложения; элементы управления и их операции недоступны
  через этот iframe.

#### Scenario: Самостоятельная вкладка

- **WHEN** пользователь открывает локальный интерфейс как верхнюю страницу
- **THEN** интерфейс загружается и разрешённые операции остаются доступны.
