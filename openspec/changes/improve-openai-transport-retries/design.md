# Точка продолжения

Статически _request_translation вызывает responses.create внутри try/except OpenAIError и преобразует ошибку в
безопасный TranslationError. Наличие внутренних повторов SDK и точная цепочка APIConnectionError ещё должны быть
установлены.

## Решения и вопросы

- Повторять только временные транспортные ошибки; постоянные ошибки API не повторять.
- Ограничить число попыток и общий бюджет ожидания; конкретные значения выбрать после диагностики и записать до
  зависимой реализации. Повторы SDK и приложения не должны перемножаться неявно.
- Не раскрывать секреты и тела запросов в диагностике; не портить уже готовые результаты.
- Проверить восстановление и исчерпание через имитации клиента, без реального платного вызова.

## Следующий шаг

Прочитать _request_translation, создание клиента и установленный SDK; зафиксировать текущие условия повторов и
воспроизвести отказ локальным тестом. SonarQube не входит в согласованную область задачи. Задача не закрыта и код не
изменён.
