# sub-translator-py

Приложение для пакетного перевода субтитров ASS, SRT и WebVTT с сохранением временных меток и оформления.
Командная строка и локальный веб-интерфейс используют общий процесс обработки с локальными и сетевыми переводчиками.

## Структура проекта

```text
.
├── sub_translate/         # Общая обработка, настройки и командный интерфейс
│   ├── translators/       # Адаптеры переводчиков и реестр моделей
│   ├── workers/           # Изолированные процессы локальных моделей
│   ├── dictionaries/      # Языковые справочники и правила обработки текста
│   ├── utils/             # Разбор форматов, кеш и публикация результатов
│   └── web/               # Локальный веб-интерфейс и пакетные задачи
├── models/                # Локальные модели
├── resources/             # Кеши и справочные данные
├── tests/                 # Модульные, форматные и браузерные проверки
├── tools/                 # Сравнение моделей и проверка качества
├── docs/benchmarks/       # Корпус, методики и результаты измерений
├── openspec/              # Требования и документация проекта
│   ├── context/           # Начало работы, архитектура, словарь и решения
│   ├── specs/             # Спецификации и инженерные правила
│   └── changes/           # Открытые изменения и задачи
└── .github/workflows/     # Автоматизация GitHub Actions
```
