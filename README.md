# sub-translator-py

Приложение для пакетного перевода субтитров ASS, SRT и WebVTT с сохранением временных меток и оформления.
Командная строка и локальный веб-интерфейс используют общий процесс обработки с локальными и сетевыми переводчиками.

## Структура проекта

```text
.
├── sub_translate/         # Общая обработка, настройки и командный интерфейс
│   ├── translators/       # Адаптеры переводчиков и реестр моделей
│   ├── workers/           # Изолированные процессы локальных моделей
│   ├── dictionaries/      # Языковые справочники и правила обработки текста
│   ├── utils/             # Разбор форматов, кеш и публикация результатов
│   └── web/               # Локальный веб-интерфейс и пакетные задачи
├── models/                # Локальные модели
├── resources/             # Кеши и справочные данные
├── tests/                 # Модульные, форматные и браузерные проверки
├── tools/                 # Сравнение моделей и проверка качества
├── docs/benchmarks/       # Корпус, методики и результаты измерений
├── openspec/              # Требования и документация проекта
│   ├── context/           # Начало работы, архитектура, словарь и решения
│   ├── specs/             # Спецификации и инженерные правила
│   └── changes/           # Открытые изменения и задачи
└── .github/workflows/     # Автоматизация GitHub Actions
```

## Запуск приложения

Команды выполняются из корня проекта в Windows x64. Нужны установленный CPython 3.14 и менеджер пакетов `uv`;
поддерживаемая среда и закреплённые зависимости определены в [pyproject.toml](pyproject.toml).
Установите рабочую среду без средств разработки:

```powershell
uv sync --frozen --no-dev
.\.venv\Scripts\sub-translate.exe --help
.\.venv\Scripts\sub-translate.exe --version
```

Для примера ниже заранее подготовьте исходный файл `subtitles\episode.en.srt` и полный каталог модели NLLB
`models\nllb-600m`; выходной файл `subtitles\episode.ru.srt` должен отсутствовать. Пути замените своими.
Подготовка и совместимость модели описаны в [модельном контракте](openspec/specs/model-runtime/spec.md).
Для примера нужен графический процессор NVIDIA, доступный PyTorch через CUDA. Для выполнения на центральном
процессоре явно добавьте параметр `--allow-cpu-fallback`.

```powershell
.\.venv\Scripts\sub-translate.exe --input "subtitles\episode.en.srt" --output "subtitles\episode.ru.srt" --from en --to ru --api nllb-600m --model-path "models\nllb-600m"
```

Локальный веб-интерфейс запускается отдельно:

```powershell
.\.venv\Scripts\sub-translate-web.exe
```

Откройте [http://127.0.0.1:7860](http://127.0.0.1:7860). Выбор профиля и файлов выполняется в интерфейсе;
его условия доступа и обработки пакета — в [веб-контракте](openspec/specs/local-web/spec.md).
